# Código de Conduta

Este projeto adota uma postura de colaboração profissional, respeitosa e orientada a soluções.

## Comportamento esperado

- Trate pessoas com respeito.
- Discuta ideias, código e decisões técnicas sem ataques pessoais.
- Seja cuidadoso ao lidar com temas jurídicos, dados pessoais e informações sensíveis.
- Ajude novos contribuidores a entender o contexto antes de exigir conhecimento prévio.

## Comportamento inaceitável

- Assédio, insultos ou discriminação.
- Publicação de dados pessoais, documentos sigilosos ou informações de processos sem sanitização.
- Incentivo a uso abusivo, invasivo ou contrário às regras das fontes consultadas.

## Aplicação

O mantenedor pode moderar discussões, fechar issues, editar comentários ou restringir participação quando necessário para proteger a comunidade e a integridade do projeto.
