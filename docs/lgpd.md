# LGPD

Este projeto foi criado para organizar informações jurídicas públicas, mas dados processuais podem conter dados pessoais, dados sensíveis, dados de crianças e adolescentes, informações de saúde, dados financeiros ou detalhes protegidos por sigilo.

## Princípios de uso

- Defina finalidade legítima antes de coletar.
- Minimize os dados armazenados.
- Evite redistribuir dados brutos quando um resumo basta.
- Controle acesso a extratos, peças e cache.
- Registre base legal e política de retenção quando houver uso institucional.
- Respeite segredo de justiça, autenticação, captcha e demais barreiras de acesso.

## Cache e arquivos locais

Cache, HTML salvo, extratos JSON e peças baixadas podem conter dados pessoais. Não envie esses arquivos para GitHub, issues públicas, logs abertos ou ferramentas de terceiros sem sanitização.

## Contribuições

Fixtures devem ser sanitizadas. Não abra pull requests com nomes reais, documentos, endereços, telefones, e-mails, dados médicos, dados bancários, documentos pessoais ou conteúdo de peças processuais não essencial ao teste.

## Aviso

Este documento é orientação técnica e não substitui avaliação jurídica específica de LGPD, ética profissional ou termos de uso das fontes consultadas.
