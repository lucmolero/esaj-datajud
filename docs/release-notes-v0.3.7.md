# esaj-datajud v0.3.7

Release visual da documentação pública.

## Destaques

- Página inicial redesenhada com hero moderno para legaltech e fluxos de IA agentica.
- Visual de pipeline jurídico com ingestão, parsing e auditoria.
- Métricas de confiança em destaque: cobertura, CI, CodeQL e LGPD.
- Cards responsivos para públicos de advocacia, legaltech e pesquisa.
- CTA mais claro para Quickstart e GitHub.
- CSS dedicado para a landing da documentação.
- Assets visuais da documentação passam a entrar no pacote fonte.

## Validação

- Build estrito da documentação validado.
- Testes automatizados mantidos.
- Build e validação de metadados do pacote executados localmente.

## Nota

Esta release não muda o contrato da API. O objetivo é elevar a percepção visual e institucional do projeto para uma apresentação open source mais moderna, confiável e profissional.
